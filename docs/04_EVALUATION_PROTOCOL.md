# 评测与实验协议

## 1. 原则

所有结论必须来自统一协议。不得把不同分辨率、不同数据划分、不同预训练数据或不同阈值策略的结果放在同一主表中而不说明。

## 2. 数据集组合

### 必做

- **MVTec AD**：标准外观异常；
- **DAGM 2007**：官方参考；
- **MVTec LOCO AD**：结构和逻辑异常；
- **MVTec AD 2**：高分辨率、小缺陷、复杂光照和分布变化。

### 推荐扩展

- VisA；
- MPDD；
- Real-IAD；
- HSS-IAD。

扩展数据集的目标不是堆数量，而是验证“不同产品、材质、光照、微小缺陷和真实工业变体”。

## 3. 四套核心协议

### P0：公开标准协议

按各数据集公开标准评测，便于与文献比较。结果只用于说明基础能力，不代表官方 100+30 场景。

### P1：官方式 100+30 适配

对每个目标产品/类别：

- 随机采 100 个正常支持样本；
- 采 30 个缺陷支持样本；
- 其余样本完全留作测试；
- 适配阶段不访问测试样本或标签；
- 报告适配时间、峰值显存和最终模型/记忆大小。

若数据集某类缺陷不足 30，应预先定义重复采样、跨缺陷采样或减少数量的规则，不能事后选择最有利方案。

### P2：未知缺陷类型留出

把缺陷类型分为 seen 与 unseen。30 个缺陷支持样本只来自 seen 类型，测试同时包含 seen 和 unseen。分别报告：

- seen F1/AP；
- unseen F1/AP；
- overall；
- 已知/未知识别准确率；
- 误把未知缺陷当成正常的比例。

这是验证 HeteroMemory 的主协议。

### P3：跨产品/跨环境泛化

- 类别留出：适配/开发与最终类别不同；
- 光照、相机、背景、旋转、模糊、压缩、曝光变化；
- MVTec AD 2 的分布变化协议；
- 高分辨率微小缺陷。

## 4. 视频与逻辑协议

建立公开可复现的视频评测：

- 正常装配序列；
- 删除步骤；
- 交换步骤；
- 重复步骤；
- 缺件或多件；
- 正常外观但错误组合；
- 帧率变化、断帧和运动模糊。

报告：事件级 precision/recall/F1、检测延迟、时间 IoU、顺序错误分类、正常视频误报率和每分钟处理帧数。

若没有足够公开视频，可从允许再分发的公开素材构建脚本化扰动集，并公开生成代码、配置和来源，不把合成视频当成真实工业数据。

## 5. 自学习/持续适配协议

按时间顺序模拟：

1. 初始 100+30 适配；
2. 新正常变体进入；
3. 新缺陷类型出现；
4. 操作员提供有限反馈；
5. 发布候选版本；
6. 再出现环境漂移。

指标：

- 更新前后新缺陷 F1；
- 旧类别 F1 变化；
- backward transfer / forgetting；
- 反馈样本效率；
- 更新耗时；
- 被安全门禁拒绝的坏版本比例；
- 回滚成功率；
- 记忆增长和模型大小。

必须加入简单经验回放基线，因为近期持续异常检测研究表明，复杂方法不一定稳定优于简单回放。

## 6. 指标

### 图像级

- AUROC；
- Average Precision；
- F1-max 和固定阈值 F1；
- accuracy（仅作为可能的官方对应项）；
- false reject / false accept；
- known/unseen 分项。

### 像素/区域级

- Pixel AUROC；
- Pixel AP；
- AUPRO；
- IoU / Dice；
- 小缺陷召回；
- 每图误报区域数。

### 可信度

- ECE；
- Brier score；
- risk-coverage / abstention；
- 未知缺陷置信度分布。

### 效率

- 适配时间；
- p50/p95/最大端到端时延；
- 预处理/推理/后处理分解；
- FPS；
- 峰值显存；
- 模型包和记忆库大小；
- 可选能耗。

## 7. 强基线

至少包含：

1. EfficientAD-S/M；
2. PatchCore；
3. AnomalyDINO 或同级 few-shot 视觉特征方法；
4. AHL 或 DRA 的开放集监督方法；
5. RealNet 或 GLASS 的合成异常方法；
6. 简单增量 PatchCore/coreset + replay；
7. 最终系统去掉每个创新模块的版本。

不能只与过时或弱基线比较。

## 8. 必做消融

### HeteroMemory

- 仅正常记忆；
- 正常 + 真实缺陷普通分类头；
- 无位置/组件条件；
- 无异质性扩展；
- 不同方向采样策略；
- 不同融合和校准。

### TriSynth

- 无合成；
- CutPaste/简单合成；
- 仅外观；
- 外观 + 几何；
- 三层合成；
- 无边界筛选；
- 有/无扩散；
- 图像空间 vs 特征空间。

### BudgetRouter

- 全图低分辨率；
- 全图高分辨率；
- 固定网格；
- 固定 top-k ROI；
- 动态硬预算；
- 不同预算-精度曲线；
- FP32/FP16/INT8。

### GuardedAdapt

- 不更新；
- 直接微调；
- 仅记忆更新；
- 回放；
- 回放 + 蒸馏/正则；
- 完整安全门禁；
- 各门禁去除。

## 9. 统计与可复现

- 主结论至少 5 seeds 或 bootstrap 95% CI；
- 对同一测试样本使用配对统计；
- 报告均值和标准差，不只报告最好 seed；
- 记录所有失败 run；
- 预先登记主指标和模型选择规则；
- 主表模型选择只使用开发集，不看最终测试结果。

## 10. 时延评测

标准命令必须能固定：

- 设备；
- 精度；
- 输入分辨率；
- batch=1；
- 预热次数；
- 测量次数；
- 包含/排除阶段；
- 电源和频率设置。

在 3090 上先做到足够裕量，但最终必须借到或购买/租用一次真实 2060 级设备测试。没有 2060 实测，不能把“满足官方要求”写入主结论。

## 11. 隐藏测试模拟器

模拟器必须：

- 从未参与开发的类别或缺陷类型采样；
- 只暴露 100+30 支持集；
- 适配后锁定模型和阈值；
- 对 1000+ 样本批量评测；
- 同时统计正确性、时延、崩溃、缺失输出和资源超限；
- 一条命令生成提交式结果和审计日志。
