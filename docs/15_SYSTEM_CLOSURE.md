# 视频逻辑与安全自学习工程闭环

更新时间：2026-08-25

## 1. 目的与边界

本文件记录两项不依赖额外神经网络的系统闭环实现：

1. `evoinspect.sequence.AssemblySequenceFSM`：把帧级步骤/组件观测转换为可审计的事件区间，
   显式报告缺件/漏步骤、重复步骤、顺序错误和未知步骤；
2. `evoinspect.guarded_adapt.GuardedAdaptController`：把操作员反馈分为可逆的即时更新和带
   回放/锚定集/影子门禁的候选模型更新，并保留版本和回滚记录。

这两项是系统工程实现，不等于已经在真实视频、LOCO 或官方隐藏数据上取得性能结果。当前
没有把合成序列或单元测试写成视频准确率、在线时延或反馈收益。

## 2. 视频序列 FSM

`FrameObservation` 只承载视觉前端已经产生的 `step`、`component`、异常分数和帧/时间戳；
FSM 不调用远程 API、不新增神经网络，也不读取测试标签。`SequenceRule` 预先声明期望步骤、
异常阈值、最大时间间隔和最小持续帧数。

输出 `SequenceEvent`，包括半开帧区间对应的起止帧、起止时间、步骤、组件、置信度和解释：

- `step_completed`：按声明顺序完成一步；
- `missing_step`：步骤被跳过、时间间隔超限或流结束前未出现；
- `reordered_step`：观察到后续步骤并同时记录被跳过的步骤；
- `repeated_step`：已完成步骤在后续步骤之后再次出现；
- `unexpected_step`：不在声明流程中的步骤；
- `anomaly`：连续异常帧合并为一个事件区间。

严格检查帧号单调性、时间戳单调性和有限数值，避免断帧或乱序输入静默改变结论。

## 3. GuardedAdapt 两级更新

### 3.1 可逆即时更新

`update_threshold` 和 `add_memory` 只改变阈值/记忆状态，必须记录反馈数据哈希、原因、旧值
和更新编号。`revert_immediate` 恢复旧阈值或移除新增记忆，但保留原审计记录，不删除历史。

### 3.2 候选模型发布

`CandidateUpdate` 必须包含父版本、候选权重路径、训练数据哈希、反馈切片 F1 前后值、锚定
回归集 F1 前后值和影子验证结果。`GatePolicy` 预先固定：

- 反馈切片最小收益；
- 锚定集最大退化；
- 是否必须通过影子验证；
- 可选模型包大小上限。

只有候选权重存在、父版本仍是 active、反馈收益达到门槛、锚定集退化不超限且影子验证通过，
才可 `publish_candidate`。旧版本标记为 `superseded` 并保留。`rollback_model` 只激活已有、
仍存在的旧权重，不重写或删除历史版本。

状态可通过临时文件原子替换写入 JSON，便于进程重启、审计和回滚演示。

## 4. 现有验证证据

- `tests/test_sequence.py`：覆盖正常步骤、连续异常区间、漏步骤/顺序错误、重复/未知步骤、
  断帧和单调性检查；
- `tests/test_guarded_adapt.py`：覆盖即时更新回滚、候选门禁拒绝/发布、锚定退化、影子失败、
  版本回滚和状态持久化；
- 全仓库 pytest：54/54 通过；新增模块 ruff 和 mypy 通过。
- `scripts/evaluate_sequence_fixture.py` 在六个预定义工程场景上识别 6/6，输出事件区间和
  解释到 `reports/experiments/system-closure-sequence-fixture-20260825T054200Z/report.json`。

这些是 CPU 工程测试证据，不是数据集指标。合成 fixture 的 6/6 只验证事件词汇和区间序列化。
真实视频协议、MVTec LOCO 评测、操作员反馈
流、影子模型训练、更新耗时、回滚成功率和端到端时延仍需独立实验登记。

## 5. 后续实验接口

1. 在 LOCO 或获许可的公开视频/脚本化扰动集上生成 `FrameObservation` 流，固定正常、漏步、
   换序、重复、缺件和断帧协议；报告事件级 precision/recall/F1、时间 IoU、检测延迟和正常
   视频误报率。
2. 在独立反馈流上先运行即时更新，再构造候选版本；保存训练数据哈希、锚定集结果、影子结果、
   发布/拒绝原因和回滚点。
3. 在真实设备上单独测量 FSM、序列化和整体视频管线时延；不得把 CPU 单元测试时间写成官方
   200 ms 证据。
