# HeteroCal-130 冲刺预注册协议

冻结时间：2026-08-30（运行任何 HeteroCal 测试指标前）  
状态：有边界的最后一个视觉方法实验；第 12 小时硬停止

## 1. 研究问题与边界

HeteroCal-130 检验一个单一问题：在完全冻结 EfficientAD-M 主模型和既有 45 个 checkpoint
的条件下，能否利用 100 正常 + 最多 30 缺陷支持集，对 Teacher-Student 局部图、
Student-Autoencoder 全局图和水平翻转一致性进行小参数非负校准，从而改善未见缺陷排序。

禁止重新训练主干、改变 256 输入、增加第六组消融、读取测试标签选择特征/参数/回退类别，
或在结果失败后继续搜索超参数。HeteroCal 不是新检测模型；它是支持集驱动的有界校准层。

## 2. 固定输入和五组消融

来源固定为 EfficientAD-M 15 类 × seeds 143--145 的 45 个最终 checkpoint。每张图提取两张
上游归一化异常图，统计最大值、top 0.1%/0.5%/1%均值、阈上面积，以及双图重叠和分歧；
水平翻转图反向对齐后计算相同统计和跨视图一致性。

只运行：EfficientAD-M、双图固定融合、缺陷类型留一校准、翻转一致性、HeteroCal-130 完整版。
主干参数不更新；残差幅度固定上限 0.35，证据权重非负，L2、步数和学习率由
`configs/innovations/heterocal_130.yaml` 一次冻结。

## 3. 支持集选择与泄漏隔离

每个 run 只用训练时未使用的正常校准样本和 support anomaly。对至少两个缺陷类型的 run，
逐类型留一：其余类型拟合，被留类型与确定性留出的正常样本评估。只有平均留出 AUROC 和
固定阈值 F1 都严格提升、且正常 FPR 不增加，才允许该 run 发布校准头；否则自动回退原始
EfficientAD-M。单缺陷类型 toothbrush 必然回退。所有测试分数和决策持久化后才打开独立
`test_truth.csv`，测试标签不参与拟合、门禁、阈值或回退。

## 4. 成功门与停止规则

完整方法必须 45/45、15 类齐全、零测试标签泄漏，并同时达到 Overall F1 >= 0.90、eligible
Unseen F1 >= 0.83、Image AUROC >= 0.97，最差类别相对 M 的 F1 下降不超过 0.01，支持集类型
留一门为正。通过后才导出并在真实 GTX2060 复测双前向端到端 p95 < 200ms。

若第 12 小时前未达到全部精度门，HeteroCal 永久降为负结果，停止算法工作；最终提交使用
PatchCore + EfficientAD-M + GuardedAdapt-v1 + 视频 FSM，不把 HeteroCal 写入简介或主视频。
