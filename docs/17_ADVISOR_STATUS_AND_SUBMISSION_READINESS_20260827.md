## 二、目前已经完成且证据可信的部分

### 2.1 固定上游 PatchCore 强基线

在 MVTec AD 15 类、seeds 133--137、100 正常 + 最多 30 个已知缺陷的隔离协议下，
75/75 个任务完成：

| 指标 | 结果 |
|---|---:|
| Overall F1 | 0.9224 |
| Image AUROC | 0.9817 |
| Unseen F1 | 0.8715 |
| Full pixel AUROC | 0.9811 |
| Pixel AP | 0.5521 |
| AUPRO@0.30 | 0.9342 |
| AUPRO@0.05 | 0.7241 |
| PRO@1% background FPR | 0.5764 |

该结果可以作为公开数据强基线和研究上界，但 PatchCore 未在 2500×2500、GTX 2060 上完成
部署验证，不能直接作为“已满足实时要求”的最终在线模型。

### 2.2 RCBR 主创新实验已经得到明确结论

RCBR 的 5000-step pilot 和唯一允许的 raw-score-space fusion 机制修订均已完成。正式批次为
四类（capsule、hazelnut、transistor、wood）× seeds 130--132，70,000 steps/任务，12/12
个结果完整，无训练日志错误。

正式 smoke gate 为 `passed=false`：

| 指标 | full RCBR | PatchCore 参考 | 差值 |
|---|---:|---:|---:|
| AUPRO@0.05 | 0.655265 | 0.639618 | +0.015647 |
| AUPRO@0.30 | 0.849750 | 0.906595 | -0.056845 |
| Image AUROC | 0.927320 | 0.987407 | -0.060087 |
| Overall F1 | 0.770043 | 0.920964 | -0.150921 |
| Unseen F1 | 0.760808 | 0.926108 | -0.165300 |
| PRO@1% background FPR | 0.564093 | 0.481752 | +0.082341 |

平均 AUPRO@0.05 的 +0.015647 低于预注册 +0.025 门槛；仅 2/4 类不下降，最差类别差值
为 -0.105517，Overall F1 和 Unseen F1 保护线也失败。因此：

- RCBR 不能作为已经验证成功的正向算法创新；
- 不允许写“提升总体性能”“优于 PatchCore”“达到实时要求”；
- 未扩展到 15 类 development，也未开启确认 seeds 138--142；
- 该实验可诚实写成受控负结果，用于说明直接高分辨率复检融合的质量退化和研究转向。

### 2.3 定位评估和报错修复

## 六、当前最严重的提交阻断项

按影响排序：

1. **没有最终部署模型。** PatchCore 是强研究基线但未通过目标硬件实时验证；RCBR 正式

3. **没有真实视频端到端演示。** 只有序列规则模块，没有视频解码、逐帧检测、事件指标和
   可视化成品。
4. **没有真实反馈闭环演示。** GuardedAdapt 只证明门禁逻辑，不证明反馈能提高模型。
5. **没有 GTX 2060/CPU 证据，且 3090 工程延迟未达到 200 ms。**
6. **没有跨数据集泛化。** DAGM、LOCO、AD 2 和 AHL/DRA 对照均缺失。
7. **没有最终使用说明、模型卡、许可证签核和清洁环境复现。**
8. **核心算法创新没有正向收益。** 可保留系统创新和诚实负结果，但竞赛新颖性、合理性
   说服力明显不足。
